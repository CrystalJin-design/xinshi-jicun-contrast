# 你的反差人格有多大？实施计划

用户最终选定单主题“你的反差人格有多大？”。本计划取代早期七主题草案，项目独立于外层已上线的塔罗网站。

**目标：** 完成可运行、适配手机的原创情境自评网站，兼顾本土共鸣、理论可追溯、结果趣味与分享。题量不被当作信效度证明；明确标注当前为待验证初版。

**技术：** React 19 / Vite 8、Express 5、Node 24内置SQLite、html2canvas、Lucide、本地字体、Playwright。服务端保存密码/会话摘要，事务限制每密码三次；随机结果链接可公开访问，报告包含已告知的少量回答摘录，不包含凭证或整份答卷。

1. 设计48道原创本土情境题：四个行为维度各五组双情境配对，共40题；另八题分别观察反馈关注与主观耗能。保留不适用选项和反向题；明确有效配对门槛。
2. 实现连续维度、变化方向与描述性反差合成分；16种主要趣味称号、中点过渡和信息不足处理。核对理论来源，公开计分规则和待实施的验证计划。
3. 完成密码验证、原子扣次、未完成测评续答、串行自动保存、网络草稿、版本冲突、幂等提交、历史报告和公开分享API。测试额度、隔离和重启持久化。
4. 实现原创米白/墨绿/暖杏视觉、密码入口、答题导航、返回修改、报告、完整PNG长图、图片预览与系统分享、复制链接、再测一次和好评后截图领取1元返现提示。
5. 执行计分/API/保存测试与生产构建；浏览器验收320–1440宽度、48题全流程、刷新恢复、公开报告、实际图片下载。模拟手机视口不能替代真实手机验收。
6. 交付本地预览、未消耗的三次体验密码、完整内容说明、启动/发码/配置/部署文档和验收记录。店铺资料保留通用说明，待实际配置；正式公网发布与真实样本研究尚未实施。
