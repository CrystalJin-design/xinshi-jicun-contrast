## 给客户发测评密码

在此项目目录执行：

```powershell
npm run cloud:codes -- create --count 100 --label 第一批发货
npm run cloud:codes -- list
npm run cloud:codes -- revoke --code 要停用的密码
```

生成的客户密码保存在本机 `data/线上发货密码-时间.csv`，每个密码最多开启三次测评。CSV不会上传GitHub。登录验证不扣次，点击开始新测评才扣次；未完成可继续。密码没有到期时间，报告链接不会因次数用完而失效；停用密码仍保留已分享报告。

## 修改网站

在 `site.config.json` 修改店铺名称、客服说明、微信和返现提示。修改界面、内容后，将代码提交并推送到此仓库 `main`，GitHub Actions自动测试、构建并发布前端。

题库、计分或店铺配置发生变化时，云端接口也需更新：

```powershell
npm test
npm run edge:prepare
npx supabase functions deploy jianji --project-ref cpoghybftxyydxyhptry --no-verify-jwt --use-api
```

该命令需要Supabase CLI登录。不要把管理密钥放入GitHub Pages或任何 `VITE_` 变量。本机 `.env.admin.local` 保存管理凭证，被Git忽略；它仅供发码和部署使用。

GitHub仓库的Actions变量 `VITE_API_URL`、`VITE_SUPABASE_PUBLISHABLE_KEY` 仅为公开调用配置。客户端不能直接读写业务表，也不能调用业务RPC；业务操作通过验证密码/会话的Edge Function执行。

## 本地开发

```powershell
npm ci
npm run dev
```

本地开发界面仍为 http://localhost:5174/ ，默认使用独立的本机测试数据库。线上密码与本地密码不通用；本地开发不会消耗线上客户的次数。
